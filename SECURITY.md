# Security Policy

Bir güvenlik veya gizlilik problemi fark ederseniz çalışan exploit, kullanıcı verisi ya da kimlik bilgilerini public issue içinde paylaşmayın. GitHub profili üzerinden geliştiriciyle özel iletişim kurun.

Bildirimde mümkünse etkilenen bileşeni, yeniden üretme adımlarını, beklenen/gözlenen davranışı ve olası etkiyi belirtin.

Depoya `.env`, anahtar deposu, imzalama anahtarı, yerel veritabanı, log veya derleme çıktısı eklenmemelidir.
